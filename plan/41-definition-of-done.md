# 41. Definition of Done

A feature is not complete merely because it compiles.

A feature is complete when:

```text
Implementation
+
Unit tests
+
Integration tests where necessary
+
Error handling
+
Documentation
+
Performance benchmark where relevant
+
No sanitizer errors
+
No known memory leaks
+
Code review
```
