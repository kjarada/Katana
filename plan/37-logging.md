# 37. Logging

Implement structured logging.

Levels:

```text
TRACE
DEBUG
INFO
WARNING
ERROR
CRITICAL
```

Log:

```text
command execution
imports
exports
database operations
survey calculations
performance events
errors
```

Avoid logging sensitive project data unnecessarily.
